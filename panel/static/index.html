Транспорты
Несколько транспортов — один туннель: клиент держит их все и переключается по приоритету (сверху вниз по типу), если один сервис заблокируют. Cups.online и Avito создают комнаты сами — ссылка не нужна.
Резерв, если сервисы недоступны. Ещё он нужен, когда Яндекс просит у сервера капчу: приложение проходит её через туннель, а для этого нужен уже работающий канал.
