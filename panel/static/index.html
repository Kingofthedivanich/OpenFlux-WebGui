Новый клиент

Несколько документов через запятую — один туннель поверх всех сразу (multi-stream): если один документ отвалится, туннель продолжит работать через остальные. У клиента должен быть тот же набор адресов.
Комнаты создаются автоматически при старте. Ссылку для клиента (--url) будет видно на карточке после добавления.
